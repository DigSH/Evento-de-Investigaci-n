# Rifa · Evento de investigación UPTC

Página de rifa con la identidad gráfica UPTC: nube de nombres (o ruleta), efectos de premio y lectura en vivo de la hoja de Google con la asistencia.

**Uso:** abrir la página → *Configurar* → pegar el enlace de la hoja (compartida como «Cualquier persona con el enlace — Lector») → *Leer la hoja* → escribir los premios → *Comenzar*.

La página no contiene datos de asistentes: la lista se lee de la hoja en el navegador de quien la abre, y los ganadores se guardan sólo en ese navegador.

`qr_formulario_evento.png`: código QR al formulario de asistencia.
